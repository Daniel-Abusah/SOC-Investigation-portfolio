
# SOC Investigation Portfolio

Practical security investigations completed in simulated training environments. These projects demonstrate my approach to investigating alerts, correlating evidence, and documenting conclusions. They do not represent production incident response engagements.

## Investigations

### The Finance Trail: Phishing, Persistence and Network Staging

[Read the case study](finance-trail-case-study.md)

**Tools and evidence:** Splunk SPL, Sysmon, Nginx web logs, Suricata, Windows Filtering Platform and Samba audit logs.

**What I practised:** Reviewing phishing-related activity, identifying process relationships, correlating file hashes, examining scheduled-task persistence, measuring callback timing and validating SMB file transfers.
